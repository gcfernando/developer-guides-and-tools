# Try an address lookup

Geocoding means finding coordinates for an address. Latitude describes north/south position. Longitude describes east/west position. The local script has a short lookup list, not a live geocoding API.

1. Run the lesson. Find North Depot in the result.
2. Change an address to Unknown Depot. It should remain unlocated.
3. For optional live practice, choose an approved geocoding service and read its request format, usage limit, privacy terms and costs. Do not use personal addresses in class.
4. Send one public place name with the required country or region. Read the response status before its coordinates.
5. Check the place on a map. Ambiguous names can match the wrong place. Keep unclear results flagged.
6. Keep any key outside code and shared files.

This local lesson needs no account or key and makes no network request. A live service is an extra task, not a completed step in this example.
