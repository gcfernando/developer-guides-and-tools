# Try storing a practice file

A cloud store holds files on a service outside your computer. This script only groups files locally. It does not upload anything.

1. Run the local lesson. Open collection_demo/deliveries.csv.
2. For an optional cloud practice, use a learning account approved by its owner. Ask about costs and deletion first.
3. In the chosen service, create a private practice storage location. Upload only the invented deliveries.csv.
4. Download it to a new local folder. Compare its column names and row count with the original.
5. Remove the practice upload when finished. Keep private data out of this exercise.

Service buttons and access rules differ. Use the selected service's own current storage guide with your account owner. This workbook does not verify a cloud deployment.
