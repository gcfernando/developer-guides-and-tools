# Developer utilities

| Utility | Purpose | Start here |
|---|---|---|
| Windows system maintenance | A fixed repair, update, networking and cleanup sequence | [Read its behavior first](powershell/system-maintenance/README.md) |
| Line-ending converter | Convert supported UTF-8 files between LF and CRLF | [Usage and limitations](powershell/convert-line-endings/README.md) |

Run each utility deliberately. The maintenance script immediately starts its complete sequence; the converter modifies the files you select.

[Configuration and service examples](../examples/README.md) are documented separately.
