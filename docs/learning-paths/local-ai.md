# Local AI Learning Path

1. Read the [local AI chat lab](../ai/local-ai-chat-lab.md) prerequisites and follow its essential path.

3. Complete the browser-chat verification checkpoint, including stop and resume.
4. Explore optional settings only after the essential path works.
