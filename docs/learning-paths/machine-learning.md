# Machine learning practical learning path

Use the [practical lessons guide](../../examples/machine-learning/ml-practical-lessons/README.md) to get the complete bundle. Follow [Python setup](../../examples/machine-learning/ml-practical-lessons/SETUP.md), then open the [workbook](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#core-course). Keep each extracted lesson's scripts and data together.

| Step | Lesson | What to demonstrate |
| --- | --- | --- |
| 1 | [002 — Your first prediction](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#your-first-prediction) | Predict delivery time, change the distance and explain the new estimate. |
| 2 | [032 — Identify missing values](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#identify-missing-values) | Identify missing inputs before preparing the data. |
| 3 | [055 — Standardize formats](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#standardize-formats) | Make dates and weight units consistent. |
| 4 | [069 — Investigate an outlier](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#spot-check-and-handle-an-outlier) | Use source evidence to correct, keep or flag an unusual weight. |
| 5 | [071 — Min-Max Scaling](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#normalization-min-max-scaling) | Reuse the fitted scaler and identify requests outside the training range. |
| 6 | [442 — Choose the right split](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#lesson-442) | Match the data split to the orders the application will receive. |
| 7 | [444 — Rare-event cutoff](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#lesson-444) | Compare missed urgent orders with false alarms; read lesson 205 first. |
| 8 | [446 — Regression evaluation](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#lesson-446) | Compare delivery errors by route, weight and zone. |
| 9 | [447 — Local model-service capstone](../../examples/machine-learning/ml-practical-lessons/Data-Science-and-Machine-Learning.md#lesson-447) | Train, evaluate and save a model, validate requests and investigate later-batch errors. |

Use the [glossary](../../examples/machine-learning/ml-practical-lessons/GLOSSARY.md) for unfamiliar terms and the workbook's lesson downloads for further practice. The supplied examples use synthetic data; use their expected outputs to understand the exercises, then record your own results.
