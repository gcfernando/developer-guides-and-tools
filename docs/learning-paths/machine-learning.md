# Data science and machine learning learning path

1. Start with the [handbook setup and Python foundations](../data-science/machine-learning-handbook.md#sec-setup-get-python-running-10-minutes). Use the [complete local bundle](../../examples/machine-learning/ml-handbook/README.md) so its datasets and illustrations are available.
2. Follow Part 0 for NumPy, pandas, charts, statistics and a first complete project.
3. Work through Part 1's data preparation, feature engineering, splitting, training and evaluation. Keep held-out data separate from training.
4. Choose a dataset exercise in Part 2 and investigate the appropriate algorithms in Part 3.
5. Use Part 4's Tkinter example to train, save, load, predict, update and roll back a model.
6. Continue into Part 5's database and JSON examples. Treat the expert sections as further study rather than a guarantee of expertise.

[Python OOP](../python/oop.md) is a useful companion when you want more class-design practice. The [SQL course](../databases/sql-server-and-mysql.md) supports database exercises, and the [AI Learning Atlas](../../apps/ai-learning-atlas/README.md) can help you choose later AI subjects.
