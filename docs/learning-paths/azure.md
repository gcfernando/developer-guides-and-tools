# Azure Learning Path

1. Start with the [Azure engineering cheat sheet](../cloud/azure/engineering-cheat-sheet.md) introduction and service decision tables.
2. Use the [resource reference](../cloud/azure/resource-reference.md) to study a resource family in depth.
3. Perform only the individual exercises appropriate to your subscription and permissions.
4. Follow each exercise's verification and cleanup instructions.

Check current official pricing, quotas, availability and lifecycle guidance before provisioning resources.
