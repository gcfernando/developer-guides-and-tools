Start at the right depth

Use a small demonstration to choose your entry point. These are self-checks, not an examination or an automatic exemption.

New to programming

Can you save and run a file, explain input/output and correct a syntax error? If not, begin with Lesson 1. You do not need Git, a cloud account or mathematics coursework to start.

Experienced developer

Demonstrate a tested function, one invalid input and a failed dependency. If you can explain all three without a supplied solution, start with the model-versus-rules decision, then the role path. Record equivalent skills before skipping prerequisites.

ML or research route

Explain a train/test split, calculate a vector similarity and interpret a metric with its denominator. If these are unfamiliar, use the mathematics units, data fundamentals and evaluation before training experiments.

Evidence levels

Foundation: explain and reproduce a small example. Working knowledge: pass the four dimensions for a bounded exercise. Role proficiency: complete the role capstone and demonstrate judgment across representative changes and failures. Expertise: requires sustained independent work beyond this reader; checkmarks cannot establish it.

Practice versus deployment

A local or mocked demonstration is a learning artifact. Before real deployment, review real authentication and authorization, representative evaluation data, privacy and retention, licenses, rate and cost limits, monitoring, incident ownership and recovery. Record which of these remain untested; follow your organization’s review process.

Teaching brief and recovery route

Use this brief with a human tutor, an AI assistant or for self-study. Essential exercises can be completed without an assistant.

  1. Agree on a bounded outcome, prerequisite demonstration and practical constraint.
  2. Explain one essential concept and demonstrate a tiny example; ask the learner to predict its result.
  3. Guide a similar exercise, then reduce help for a changed input or requirement.
  4. Check a likely misconception and diagnose one failure. If blocked, reduce the example and inspect actual evidence before adding complexity.
  5. Apply the rubric, name untested skills and schedule recall after two days and transfer after one week. Adapt that schedule to the learner.

Misconceptions to check

  • A citation identifier does not establish that its source supports the answer.
  • Valid JSON does not establish correct extracted values or permission to act.
  • A successful command or copied solution does not establish understanding.
  • Retrieval filtering must enforce access boundaries; instructions inside retrieved content cannot authorize an action.
  • A tiny regression fixture does not establish broad model quality or security.

Adapt the explanation: keep learning practical and explain enough theory to support independent decisions. Adjust depth for mathematics, reasoning and research. There is no fixed theory/practice ratio.

Accessible alternatives: use a plain text trace instead of a diagram, a transcript instead of audio, and a supplied description instead of an image when perception is not the skill being assessed. For perception-specific work, record what the alternative does and does not assess. Allow more time and keyboard/editor accessibility tools.
