🎨 What the learning priorities mean

The same topic can be essential for one profession but optional for another.

🟢 Essential — learn first🟡 Recommended — learn next🟣 Advanced — specialize🔵 Optional — later⚪ Not required now — skip safely

Learning depth: Awareness = explain it; Working = do it with reference material; Proficient = build and troubleshoot independently; Expert = design complex solutions and mentor others.
