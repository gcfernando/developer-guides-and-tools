## Offline reading and practice

Keep this complete folder, including `scripts/`, together and open any guide's HTML file in a browser. Cross-links and script downloads use relative paths. External documentation links require internet access.

The companion PowerShell and shell scripts create a `review-practice` repository in the current working directory, write example files and agent configuration, and create local Git commits. Read the selected guide and script first. Run setup only in a disposable practice location with Git installed and a Git commit identity configured, not inside this resource repository. Node.js and the relevant AI client are needed for the practice exercises; account access may have costs.

The guide files are maintained directly, not generated by the shared repository build. Product commands and model availability can change; consult each guide's official source links. Moving and publishing these files does not verify their recorded examples or setup scripts.
