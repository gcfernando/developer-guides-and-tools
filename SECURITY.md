# Security reporting

Do not include credentials, private data or confidential source in public reports. If the repository has private vulnerability reporting enabled, use its Security tab. Otherwise arrange a private channel with the maintainer before disclosing sensitive details; no private contact address is assumed here.

Examples and references may change files, data, container environments, system configuration or cloud resources. Use them only in environments you are authorized to administer.

The Windows maintenance script has no dry-run mode and starts its complete sequence. Read its companion documentation. Configuration snapshots and command catalogs are not scripts to execute from top to bottom.

This repository does not define a security response SLA or claim that every example is tested on every platform.
